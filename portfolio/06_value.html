Project Value Noise

3D Graphics

Project Overview

In this project, I implemented a procedural Value Noise generation pipeline in C++ and visualized the results using OpenGL shaders. Value noise maps discrete coordinates to random values using a permutation hash function, then interpolates between them (linear for 1D, bilinear for 2D, and trilinear for 3D) to produce smooth gradients. The demo includes various procedural patterns like Fractal Sum, Turbulence, Marble, and Wood, along with customizable interpolation smoothing methods (Linear, Cosine, Smoothstep, and Quintic).

Tasks Completed

  • N-Dimensional Noise (1D, 2D, 3D): Built a templated ValueNoise class supporting linear, bilinear, and trilinear interpolation depending on the noise dimension.
  • Permutation Hashing: Utilized a randomly shuffled permutation table generated at construction time to perform fast, cache-friendly grid hashing (PermutationHash.hpp). This enables seamless, tileable coordinate wrapping based on power-of-two period sizes.
  • Interpolation Smoothing: Programmed math functions to apply different interpolation curves (Linear, Cosine, Smoothstep, and Quintic/fade) to smooth out the transition boundary between grid nodes.
  • OpenGL Shader Integration: Developed simple.vert and simple.frag GLSL shaders to render generated textures on a full-screen quad, scaling texture coordinates using uniform variables to verify tiling properties.
  • Dynamic Texture Uploading: Added an optimized UploadAsRGBA method to the Texture class, utilizing glTexSubImage2D for fast, real-time CPU-to-GPU pixel data uploads.
  • Job System Integration (Desktop): Integrated a multi-threaded C++ thread pool (JobSystem) using std::thread, mutexes, and condition variables to parallelize noise calculations on desktop platforms.
  • Multi-Frame Slicing (Web): Implemented a timed slice generator as a fallback for platforms that do not support multithreading (like Web/Emscripten). This distributes the computation over multiple frames so that the browser tab doesn't freeze during high-resolution texture generation.
  • ImGui Controls: Integrated controls to dynamically change the period size, smooth method, texture resolution, tiling scale, and pattern types (Plain Value, Fractal Sum, Turbulence, Marble, Wood) with real-time feedback.

Reflection

One of the primary challenges was ensuring that the noise texture tiles seamlessly when repeated. By enforcing power-of-two dimensions and utilizing a bitwise mask (e.g. x & (period - 1)), I aligned the permutation lookup wrapper perfectly. This guarantees that sampling at the right edge blends identically with the left edge.

Another major learning point was handling the computational performance discrepancy between desktop and web builds. While the multi-threaded JobSystem yields instantaneous updates on desktop, web platforms struggle with standard threads. The multi-frame timed slicing state machine solved this beautifully, allowing the demo to remain interactive on the web without dropping frames.
