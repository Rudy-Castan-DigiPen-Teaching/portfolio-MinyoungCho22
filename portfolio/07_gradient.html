Project Gradient Noise

3D Graphics

Project Overview

In this project, I implemented hardware-accelerated Improved 3D Perlin Gradient Noise on the GPU using GLSL shaders. Gradient noise defines pseudo-random gradient vectors at grid corners, computing the final value through dot products and interpolation. Unlike CPU-based generation, this project utilizes an offscreen framebuffer with a single-channel float texture (R32F) to compute noise values on-the-fly, allowing high-resolution real-time generation and seamless tiling.

Tasks Completed

  • Graphics Framework Extension: Enhanced the Texture and FrameBuffer classes to support floating-point color formats (RGBA8, RGBA32F, R32F) for high-precision offscreen storage.
  • Improved Perlin Noise GLSL Implementation: Developed a GPU-based 3D Perlin noise shader utilizing the quintic smoothing/fading curve (6t^5 - 15t^4 + 10t^3) and 12 fixed gradient directions cycled periodically.
  • Real-Time Noise Patterns: Programmed five distinct procedural patterns directly in GLSL: Plain Gradient, Fractal Sum, Turbulence, Marble (utilizing gl_FragCoord.x for column-relative sin waves), and Wood.
  • Seamless Tiling: Configured a bitwise-and coordinate wrapping method matching the period size (64) to ensure the noise tiles seamlessly when repeated on a surface.
  • 2D Slice & 3D Terrain Visualization: Implemented texture rendering for flat 2D noise visual slices and developed surface.vert to dynamically displace a flat plane mesh into a 3D terrain representation.

Reflection

Implementing the entire noise pipeline on the GPU highlighted the performance benefits of shader-based generation over CPU calculations. While CPU-based Value Noise required chunked slicing or multithreading to avoid freezing, GPU-based Gradient Noise computes millions of pixels instantly at high framerates.

Aligning the noise displacement visually with the color map on the 3D surface mesh was a key learning experience. It required using the same tiled texture coordinates in both surface.vert (for physical displacement) and simple.frag (for visual coloring).
