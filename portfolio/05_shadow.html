Project Shadow Mapping

3D Graphics

Project Overview

In this project, I implemented real-time Shadow Mapping in a custom C++ graphics framework utilizing OpenGL. Shadow mapping is a multi-pass technique where we first render the scene's depth from the perspective of the light source (which is treated as a camera) into a custom Depth Framebuffer Object (FBO). In the second pass, we render the scene from the spectator camera's viewpoint, transforming each fragment's position into the light's coordinate system to sample the depth texture and determine whether the fragment is in shadow.

Tasks Completed

  • FrameBuffer Class Implementation: Developed the FrameBuffer class in C++ to manage custom render targets, allowing seamless binding, unbinding, and attachment of color and depth textures (FBO).
  • Depth and Color Textures: Extended the Texture wrapper class to support depth map allocation with various bit sizes (16, 24, and 32-bit components) and custom comparison modes/filters (GL_COMPARE_REF_TO_TEXTURE, GL_LEQUAL).
  • Light Camera Matrix Calculations: Programmed high-performance basis-vector conversions inside the Camera class, computing ViewMatrix and ToWorldMatrix transformation matrices.
  • Multi-Pass Rendering System: Implemented the dual-pass rendering loop: the first pass renders to the depth FBO with front-face culling to mitigate shadow acne, and the second pass renders to the screen with back-face culling and custom shadow sampling.
  • Projection Shadow Mapping Shaders: Programmed GLSL vertex and fragment shaders utilizing sampler2DShadow and textureProj to perform perspective-divided depth comparisons, incorporating support for suppressing shadows behind the light.
  • Visual Debug Helpers: Created interactive visualizers to render the light's frustum as a transformed wireframe cube and display the depth texture mapped onto a screen-aligned quad.
  • Atmospheric Effects: Applied exponential fog calculations based on fragment distance and custom colors, along with gamma correction ($2.2$).

Reflection

One of the primary challenges was handling "shadow acne"—self-shadowing patterns caused by limited depth precision. I resolved this by rendering front-facing geometry instead of back-facing geometry during the depth map pass (using front-face culling), and adding a tunable slope-scaled depth bias via glPolygonOffset.

Additionally, constructing the transformation matrices for the light camera from basic orientation vectors without using generic inverse operations was highly educational. It showed how matrix properties (like orthonormality) can be used to construct the inverse view matrix (the world matrix) directly.
